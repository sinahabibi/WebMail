# 📧 WebMail Client (کلاینت ایمیل تحت وب)

A lightweight, stateless, and fully responsive web-based email client built with ASP.NET Core.  
یک کلاینت ایمیل تحت وب سبک، بدون وضعیت (Stateless) و کاملاً واکنش‌گرا که با ASP.NET Core توسعه داده شده است.

---

## 🇬🇧 English Documentation

### 🚀 Overview
This project is designed to provide a completely free, easy-to-use, and highly secure webmail interface. It acts as a direct, real-time bridge to your email server without requiring any complex infrastructure or heavy server resources.

### ✨ Key Features
* **100% Free & Open Source:** Built for the community and consumers, completely free of charge.
* **Zero Prerequisites & No Database:** Incredibly easy to deploy. It requires absolutely no database setup, background services, or caching servers.
* **Privacy-First (Stateless):** Your data is solely yours. Absolutely **nothing** (no emails, no credentials, no user data) is stored or saved on the server. It connects directly to your mail server on the fly.
* **Bilingual Interface:** Native built-in support for both English and Persian (Farsi) languages.
* **Simple Configuration:** Built-in setup and configuration system to get you running in seconds.

### 💻 Tech Stack
* **Backend:** ASP.NET Core, C#, MVC Architecture
* **Frontend:** HTML5, CSS3, Bootstrap, jQuery

### 🛠️ Getting Started
1. Clone the repository.
2. Open the solution (`WebMail.slnx`) in Visual Studio or your preferred IDE.
3. Run the project (`dotnet run`).
4. Follow the initial setup on the screen to connect to your IMAP/SMTP server.

## 🇮🇷 راهنمای فارسی

### 🚀 معرفی پروژه
این پروژه با هدف ارائه یک رابط کاربری وب‌میل کاملاً رایگان، با استفاده آسان و امنیت بالا برای مصرف‌کنندگان طراحی شده است. این سیستم به عنوان یک رابط مستقیم و در لحظه با سرور ایمیل شما عمل می‌کند و نیازی به هیچ‌گونه زیرساخت پیچیده ندارد.

### ✨ ویژگی‌های کلیدی
* **کاملاً رایگان:** توسعه یافته برای دسترسی عموم و استفاده مصرف‌کنندگان به صورت کاملاً رایگان.
* **بدون هیچ‌گونه پیش‌نیاز (بدون دیتابیس):** نصب و راه‌اندازی این پروژه فوق‌العاده آسان است. هیچ نیازی به نصب دیتابیس، سرویس‌های پس‌زمینه یا سرورهای کش ندارد.
* **حفظ کامل حریم خصوصی (بدون ذخیره‌سازی):** امنیت و حریم خصوصی در بالاترین سطح ممکن قرار دارد. **هیچ چیزی** (اعم از محتوای ایمیل‌ها، رمزهای عبور یا اطلاعات کاربری) روی سرور ذخیره نمی‌شود. تمام اطلاعات فقط در لحظه از سرور ایمیل شما خوانده می‌شود.
* **پشتیبانی کامل از زبان فارسی:** دارای رابط کاربری دو زبانه (فارسی و انگلیسی) به صورت پیش‌فرض و هماهنگ با تقویم و ساختار راست‌چین (RTL).
* **پیکربندی سریع:** دارای سیستم راه‌اندازی اولیه (Setup) ساده برای ورود و استفاده در کمترین زمان ممکن.

### 💻 تکنولوژی‌های استفاده شده
* **بک‌اند (Backend):** ASP.NET Core, C#, معماری MVC
* **فرانت‌اند (Frontend):** HTML5, CSS3, Bootstrap, jQuery

### 🛠️ راهنمای شروع و راه‌اندازی
۱. پروژه را کلون (Clone) کنید.
۲. فایل سلوشن (`WebMail.slnx`) را در Visual Studio یا محیط توسعه دلخواه خود باز کنید.
۳. پروژه را اجرا کنید (`dotnet run`).
۴. مراحل ساده پیکربندی اولیه را در مرورگر طی کنید تا به سرور IMAP/SMTP خود متصل شوید.
